# Optimization for AI — Lesson 7

**Topic:** Regularization and Generalization  
**Animation framework:** Manim Community Edition  
**Video output:** Not rendered by this project generator; render scenes locally.

This project provides a reproducible synthetic regression experiment, five Manim scenes, prompts for lesson production, and tests. The numerical experiment is the source of truth for the narration and animation labels.

## What the experiment demonstrates

- 18 noisy training observations generated with seed 42.
- 100 separate validation observations generated with seed 123.
- Polynomial degree 3 versus degree 12.
- L2 objective: `MSE + lambda * sum(beta_j ** 2)`.
- L1 objective: `MSE + lambda * sum(abs(beta_j))` via proximal gradient.
- Intercepts are not penalized; polynomial features are standardized using training data only.

All data are synthetic and only intended for teaching. Train/validation MSE values are properties of this fixed dataset, not universal model rankings.

## Setup

Use Python 3.11 or 3.12 in a virtual environment. Manim's system requirements vary by OS. Install the system dependencies listed in the official Manim Community installation guide, including FFmpeg and a supported LaTeX installation for `MathTex` formulas.

### Windows PowerShell

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -e ".[dev]"
```

If the `manim` command is not recognized after installation, run `python -m manim --version` to confirm the environment, and reopen the terminal after installing system dependencies.

### Run the numeric experiment

```bash
python examples/run_experiment.py
```

This prints model metrics and creates `outputs/lesson7_model_fits.png`.

### Run tests

```bash
pytest -q
```

### Render Manim scenes

Render every scene at preview quality with the helper script: 

```bash
python animations/render_all.py --quality low
```

Render just the L2 scene: 

```bash
python animations/render_all.py --quality low --scene l2
```

Control playback speed with `--speed`: `1` is normal speed, `0.5` is half speed, and `2` is double speed. Values from `0.25` to `4` are supported. Changing speed requires FFmpeg; the default speed does not.

```bash
python animations/render_all.py --quality low --scene l2 --speed 0.75
```

The helper supports `low`, `medium`, `high`, and `production` quality. Alternatively, render each scene directly at preview quality:

```bash
manim -pql animations/lesson7_scenes.py OverfittingHook
manim -pql animations/lesson7_scenes.py TrainValidationGap
manim -pql animations/lesson7_scenes.py L2Regularization
manim -pql animations/lesson7_scenes.py L1VersusL2
manim -pql animations/lesson7_scenes.py RegularizationStrengthAndRecap
```

Render 1080p quality after review:

```bash
manim -pqh animations/lesson7_scenes.py OverfittingHook
```

Manim writes rendered media under its `media/` directory by default. These commands render MP4s; this package intentionally does not include pre-rendered Manim videos.

## Important teaching notes

- Training loss measures fit to training examples; validation loss estimates performance on separate examples.
- Lower training loss does not guarantee better generalization.
- L2 tends to shrink weights; L1 can produce sparse coefficients.
- Too much regularization can underfit.
- Regularization can help, but does not guarantee generalization and does not replace a final held-out test set.

## Manim vs Matplotlib

Manim is useful for authored, scene-based mathematical storytelling: formulas, labels, model curves, and metrics can appear together at carefully timed moments. Matplotlib is still simpler for quick static plots and exploratory charts. This repo uses Manim for the lesson's animations and Matplotlib only for a quick preview image.
